## Compatibility retained with current callers

- Remote Browser operation-name translation is called by Server Core and the Desktop broker.
  Removing it would disable current Remote Browser operations.
- Task owner/team filters implement the active personal-only and explicit-team task queries.
  Their historical compatibility wording does not make the code obsolete.
- Handoff `swapLead` can rejoin an old lead during rollback. Keep the transactional rollback path.
- Database migrations, provider session recovery, platform-specific behavior, packaged executable
  resolution, and security checks still support current local data and installations.
- Git author identities and ordinary GitHub attribution links are outside the requested path/IP
  rewrite. No identity anonymization policy was inferred from this request.
